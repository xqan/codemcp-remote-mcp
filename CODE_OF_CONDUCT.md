# Code of Conduct

codemcp-remote aims to maintain a technical community where contributors can disagree rigorously without personal hostility.

## Expected behavior

Participants should:

- discuss code, evidence, trade-offs, and risks rather than attacking people;
- give reproducible technical context when reporting problems;
- respect privacy and never publish another person's credentials, private logs, or confidential source code;
- accept maintainers' security restrictions when they protect users from unsafe execution paths;
- disclose conflicts of interest that materially affect a technical or security recommendation.

## Unacceptable behavior

The project does not accept harassment, threats, discriminatory abuse, deliberate disclosure of private information, credential exposure, or attempts to pressure maintainers into bypassing security review.

## Enforcement

Maintainers may edit, hide, lock, or remove contributions that violate these rules and may restrict participation for repeated or serious violations.

Security reports containing sensitive information must be sent through the private process described in `SECURITY.md`.

For ordinary conduct concerns, contact the project maintainer privately using the contact information published in the repository metadata. Include enough context for the concern to be reviewed without unnecessarily redistributing private material.
